1. **DESCRIPCIÓN DE LA IDEA**

NotifyMeBus (nombre provisional) es un proyecto que trabaja sobre la empresa municipal de transportes de Madrid. El proyecto viene, como la mayoría de soluciones digitales exitosas, de una necesidad que no está cubierta. Y es que cuando un usuario se encuentra esperando al bus, tiene que mirar constantemente cuanto le queda al bus, tiene que hacer una comprobación **activa**, que si el usuario tiene otras actividades en el momento puede ser un problema. Ahí entra NotifyMeBus, y convierte esa tarea activa y inconveniente, en una simple espera **pasiva** en la que el usuario especifica cuanto tiempo quiere que le falte al bus para llegar a la parada designada para que se le notifique, es decir, que la aplicación te notifique cuando le queden x minutos al bus, y el usuario elige el valor de x, esta aplicación se construirá alrededor de esa idea, pero también cumplirá con las funcionalidades estándar que tiene una aplicación de autobuses normal.
